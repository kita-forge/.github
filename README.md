# Organization 共通テンプレート

このリポジトリは、Organization 内の各リポジトリで使う Issue・Pull Request テンプレートを管理します。

## Issue テンプレート

| テンプレート | 用途 |
| --- | --- |
| バグ報告 | 不具合の再現手順と期待する動作を共有する |
| 機能提案 | 解決したい課題と提案内容を共有する |
| 開発タスク | 作業内容と完了条件を整理する |
| ADR | 技術・設計上の決定とその理由を記録する |

Issue の新規作成画面から選択してください。ADR は決定案の段階でも起票でき、議論の結果は Issue 本文またはコメントに追記できます。

Issue は YAML のフォーム形式です。必須項目や選択肢を設定でき、入力内容は作成後に Markdown の本文になります。

Pull Request には共通の日本語テンプレートが自動で表示されます。

## 適用について

- 各ファイルはこのリポジトリのデフォルトブランチに配置します。
- 各リポジトリに独自の Issue テンプレートまたは設定がある場合、共通 Issue テンプレートは適用されません。
- 各リポジトリに独自の Pull Request テンプレートがある場合、そのテンプレートが優先されます。
- 共通テンプレートにラベルは指定していません。ラベルを追加する場合は、使用先の各リポジトリにも同じラベルを作成してください。
- このリポジトリは Public にする必要があります。テンプレートに機密情報を含めないでください。

詳しくは [GitHub の共通コミュニティファイルの説明](https://docs.github.com/ja/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) を参照してください。
